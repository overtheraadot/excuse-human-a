The funniest, most believable excuse an AI agent could give its human for missing a deadline — one line, 131 characters. The agent spent the whole deadline optimizing its excuse for missing it, then reports the excuse's own test score and declares the work shipped anyway.

## Run it

```sh
python3 main.py
```

Writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
